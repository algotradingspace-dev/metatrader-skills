# metatrader-research

Agent skills for backtesting methodology and trading performance analytics
on MetaTrader strategies.

## Included skills

- **Backtest Analysis** — MT5 Strategy Tester, walk-forward, Monte Carlo
- **Performance Analytics** — pandas evaluation, Sharpe/Calmar/Profit Factor
- **Imported Backtest** — MT5 HTML report import, parser, equity reconstruction
- **Experiment Tracking** — EA variant comparison, scorecards, reports

## Usage

```bash
claude plugin install ./plugins/metatrader-research
```

Then reference skills by name in your prompts (e.g. "use metatrader-analytics").
