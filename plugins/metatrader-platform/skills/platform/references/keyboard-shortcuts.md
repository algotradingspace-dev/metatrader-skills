# Keyboard Shortcuts

**Note:** User-assigned hotkeys take priority over predefined ones.

---

## Chart Window

| Key | Action |
|-----|--------|
| `←` | Scroll chart left |
| `→` | Scroll chart right |
| `↑` | Fast scroll left (fixed scale: scroll up) |
| `↓` | Fast scroll right (fixed scale: scroll down) |
| `5` (numpad) | Restore automatic vertical scale |
| `Page Up` | Fast scroll left |
| `Page Down` | Fast scroll right |
| `Home` | Move to chart start |
| `End` | Move to chart end |
| `-` | Zoom out |
| `+` | Zoom in |
| `Delete` | Delete all selected graphical objects |
| `Backspace` | Delete latest imposed object |

---

## Global (Independent of Active Window)

| Key | Action |
|-----|--------|
| `Ctrl+M` | Task Manager |
| `Ctrl+E` | EA properties dialog |
| `Ctrl+O` | Chart setup window |
| `Ctrl+F7` | EA input parameters |
| `Ctrl+G` | Chart list window |
| `Ctrl+H` | Arrange indicator window heights |
| `Ctrl+I` | Indicators List |
| `Ctrl+B` | Objects List |
| `Ctrl+L` | Show/hide OHLC line |
| `Ctrl+V` | Show/hide real volumes |
| `Ctrl+S` | Save chart (CSV/PRN/HTM) |
| `Ctrl+W` / `Ctrl+F4` | Close current chart |
| `Ctrl+Y` | Show/hide period separators |
| `Ctrl+Z` / `Alt+Backspace` | Undo object deletion |
| `Ctrl+F6` | Previous chart window |
| `Ctrl+Tab` | Next chart window |
| `Ctrl+←` | Previous profile |
| `Ctrl+→` | Next profile |
| `Alt+1` | Bar chart |
| `Alt+2` | Candlestick chart |
| `Alt+3` | Line chart |
| `F1` | Bars view |
| `F2` | Candles view |
| `F3` | Line view |

## Market Watch

| Key | Action |
|-----|--------|
| `F9` | New Order window |
| `Space` / `Tab` | Switch tabs (Symbols/Details/Trading/Ticks) |
| `A` | Auto-arrange columns |
| `G` | Show/hide grid |

## Navigator

| Key | Action |
|-----|--------|
| `Insert` | Open new account (when Accounts section selected) |
| `Delete` | Delete selected item |
| `G` | Show/hide grid (Favorites tab) |

## Toolbox

| Key | Action |
|-----|--------|
