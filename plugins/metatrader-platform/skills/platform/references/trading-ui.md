# Trading UI Foundations and Advanced Topics

The base trading workflow is: understand instrument settings, watch quotes,
inspect DOM if available, send or modify orders, then review results
through history and reports.

---

## Trading Workspace Map

| Tool | Primary use |
|------|-------------|
| General trading concepts | Order types, execution types, fill policies, trailing stops, baseline terminology |
| Depth of Market | Best bid/ask ladder plus Time & Sales / tick-chart context where supported |
| Market Watch | Quotes, price statistics, symbol specification entry points, and one-click trading access |
| One Click Trading | Fast order entry where timing matters more than full ticket review |
| Options Board | Option-chain style view plus implied-volatility and strategy analysis support |
| Trading report | Visual account-performance review for risk and stability analysis |

---

## Advanced Trading Topics

| Topic | Terminal-side concern |
|-------|----------------------|
| Price data | Quote formation and market-depth behaviour vary by market type |
| Margin forex / futures | OTC and futures margin rules, conversion to deposit currency, spread discounts |
| Margin exchange | Exchange-style terminology and broker discount schemes |
| Collateral instruments | Non-tradable assets that still contribute to margin support |
| Custom instruments | User-defined synthetic symbols for charting, analysis, and tester use |
| Spreads | Preferential margin handling for correlated, oppositely directed positions |
| Futures | Variation-margin specifics and end-of-day handling |
| History report | Advanced account-statement analysis and export workflow |
